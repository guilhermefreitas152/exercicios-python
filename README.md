## Descrição
Este repositório reúne 25 exercícios feitos em Python.
Os exercícios praticam entrada e saída de dados, variáveis, condicionais, laços de repetição e listas.

## Tecnologia utilizada
- **Linguagem:** Python 3
- Para conferir a versão instalada, execute `python --version` no terminal.

## Como executar
1. Abra a pasta do projeto no Visual Studio Code.
2. Abra o terminal na pasta do projeto.
3. Entre na pasta do exercício desejado.
4. Execute o arquivo com `python ex01.py`, substituindo `ex01.py` pelo nome do arquivo.

Cada exercício é independente e pode ser executado separadamente.

## Índice dos exercícios

### Parte 1 — Variáveis, entrada e saída
- `parte1-variaveis/ex01.py` — Exibe nome e idade.
- `parte1-variaveis/ex02.py` — Soma dois números.
- `parte1-variaveis/ex03.py` — Calcula a área de um círculo.
- `parte1-variaveis/ex04.py` — Converte Celsius para Fahrenheit.
- `parte1-variaveis/ex05.py` — Calcula o valor total de uma compra.

### Parte 2 — Condicionais
- `parte2-condicionais/ex06.py` — Verifica se um número é par ou ímpar.
- `parte2-condicionais/ex07.py` — Compara dois números.
- `parte2-condicionais/ex08.py` — Identifica se um número é positivo, negativo ou zero.
- `parte2-condicionais/ex09.py` — Classifica a média do estudante.
- `parte2-condicionais/ex10.py` — Verifica a idade mínima para votar.

### Parte 3 — Repetição com while

### Parte 4 — Repetição com for

### Parte 5 — Listas
- `parte5-listas/ex21.py` — Cria e exibe uma lista com cinco números.
- `parte5-listas/ex22.py` — Calcula a soma dos itens da lista.
